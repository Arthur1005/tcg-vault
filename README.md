# My TCG Vault

Personal Pokémon TCG collection tracker (promos, graded slabs, sealed). Installable as a Home Screen app; data stays on the device.

Card data: PokemonTCG/pokemon-tcg-data and TCGdex (MIT). Sealed products: pkmjson by ArthurG-data (CC BY 4.0), TCGplayer catalogue via TCGCSV / pokesave-data, Cardmarket catalogue via binder-tcg-data. Card images are loaded from pokemontcg.io and TCGdex.
